## 玩法概述

你是"启元一号"托卡马克的**当班运行总工程师**。一局游戏共 **4 轮**，每轮：

1. **听取四份专家简报** —— 每位专家只精确掌握自身负责仪表的数据，信任度决定其简报精度。
2. **交叉验证仪表** —— 拼合四份信息片段，与客观仪表读数对照，推断故障位置。
3. **拖放经费修复** —— 把有限的经费代币（每轮 100 单位）拖到装置四部位投资。
4. **提交结算** —— 在正确部位投足修复阈值即识破根因，推进下一轮。

四轮故障并非孤立，而是源自**三个根本原因**的耦合表现：

| 根本原因 | 表象仪表 | 修复部位 | 关联专家 |
|----------|----------|----------|----------|
| 磁体电源老化 | 环向场强度下滑 | 环向场磁体线圈 | 磁体工程师 |
| 第一壁微裂纹 | 第一壁温度升高 | 第一壁内衬 | 材料与第一壁负责人 |
| 氚提取泵效率下降 | 氚自持率走低 | 氚增殖包层 | 氚循环工程师 |

### 结局矩阵

最终结局由 **2D 矩阵**决定，共 **12 种**：

- 横轴：最终 Q 值区间（`<1` / `1~1.1` / `>1.1`）
- 纵轴：识破的根本原因数量（`0` / `1` / `2` / `3`）

从「全盘失守」到「聚变之星」，每种结局给出不同科普总结，鼓励重玩。

此外另有 **2 个隐藏结局**，由系统状态自然触发（而非矩阵）：长期无视致不可逆损伤拉满并破裂 →「连锁熔毁」；高增益点火 + 三根因全识破 + 零损伤 + 全程未破裂 →「完美一班」。

| 操作 | 方式 |
|------|------|
| 投资经费 | 从经费池**拖拽**代币到装置部位 |
| 撤回投资 | 在部位上**右键** |
| 即时效果 | 投资后部位健康条与核心指标实时回显**当前实际效果**（不再做悬停假想预测试探） |
| 深度诊断 | 点击简报卡上的「深度诊断 ¥10」 |
| 运行手册 | 点击按钮或按 **H** |

| 科普标签 | 投资时部位旁浮现，3 秒自动消退，**点击钉住** |

## 专家系统

四位专家不再"说谎"——改为**信任度 → 情报精度**模型：

- **信任度 ≥ 0.5**：输出精确简报（窄区间 / 确定语气），便于交叉验证。
- **信任度 < 0.5**：输出模糊简报（宽区间 / 含糊措辞），需多方拼合。
- 每位专家只对自身负责仪表（`direct_gauge`）有直接精确数据，对他人部位只能间接推断。

**信任度变化规则**：对症投入（该专家负责部位有故障且投入达比例）→ 信任 +；完全无视其警告 → 信任 −。

| 专家 | 性格 | 负责仪表 |
|------|------|---------|
| 磁体工程师 | 老派稳妥 | 环向场强度 |
| 材料与第一壁负责人 | 激进冒险 | 第一壁温度 |
| 氚循环工程师 | 悲观预警 | 氚自持率 TBR |
| 等离子体物理师 | 理想主义 | 等离子体温度 |

**深度诊断**：消耗 ¥10 经费，可获取某专家负责仪表的近三轮读数趋势 + 该专家的语气解读（不判定故障真假，需自行甄别）。

## 进阶机制

### 超额投入奖励
同一部位本轮投入 ≥ 50 单位 → 下一轮该部位关联根因故障强度降低 5%，对应仪表显示「✓稳定」角标。奖励不跨轮累积，鼓励专注投入而非平均分配。

### 不可逆损伤
某部位有故障却长期投入严重不足 → `irreversible_damage` 等级累积 → 后续轮该部位故障强度持续放大。这是游戏内的真实内生后果，而非外部计时压力。

### 故障链耦合（第 3 轮后）
主因（磁体老化）未修复时，次因仪表（第一壁温度）会出现与主因同步的周期性尖峰，显示「⇌链路」角标。玩家需判断：优先修主因消根源，还是先给次因降温争取时间。

### 稳定度历史
连续两轮稳定度下降时，提交反馈中出现内生风险警告，提醒决策后果正在累积。

### 逻辑一致性提示
提交前若检测到分配方向与本轮最强故障表象明显矛盾（对应部位零投入却重投他处），弹出一次温和提示。不评判对错，可继续提交。

### 锁定预览（决策收束）
取消实时悬停试探，改为：分配期间仅回显**已投入的实际效果**；点「提交本轮」后弹出一次性**锁定预览**（结果颜色 / 趋势 / 参数升降），短倒计时逾期自动确认。决策一旦锁定不再反复试探，更贴近真实排障的"下注"压力。

### 手作剧本随机（重玩价值）
每局开局从 **5 套手作剧本**中随机抽取（标准 / 磁体—第一壁耦合 / 氚提取连锁 / 三重危机 / 隐蔽渐变）。剧本驱动当局的**激活根因子集、仪表基准偏移、故障链组合与触发轮、专家立场（谁精确 / 谁模糊）**——专家人设固定、角色由剧本指派。所辖子系统本局无故障的专家给中性简报，不陈述不存在的故障（恪守"专家不说谎")。连开两局，根因 / 链 / 立场 / 数值均不同。

### 复盘三图
结算后可调出三张对比图，纯视觉教学、**无"最优方案"标注**：① 经费分配比例；② 各轮实际故障强度变化；③ 关键仪表跨轮趋势。识别"渐变 vs 突发"故障模式。

### 行为成就
庆祝多样性玩法，不暗示唯一最优解：

| 成就 | 触发条件 |
|------|---------|
| **偏听则暗** | 全程无视某专家，仍Q≥1点火 |
| **耦合猎手** | 某轮一次识破 ≥2 个根因 |
| **烈火中永生** | 稳定度曾跌破破裂阈值，最终挽回 |
| **预算狂人** | 总花费 < 标准线 80% 且 Q≥1 通关 |

## 难度模式

| 模式 | 限时 | 仪表噪声 | 精度提示 | 建议提示 | 历史日志 |
|------|------|----------|----------|----------|----------|
| **新手 / 科普** | 不限时 | 无 | ✓ 精确/模糊标签 | ✓ 角标 | — |
| **总工** | 300s | 低频正弦（可识别） | — | — | ✓ |
| **自定义** | 240s | 正弦（较弱） | — | — | ✓ |
| **挑战** | 180s | 正弦（强） | — | — | ✓ |

> 总工 / 挑战模式的仪表噪声为**确定性低频正弦**，跨轮平滑变化、多轮可识别周期，从而与真实异常区分。限时耗尽自动提交并触发稳定度延迟惩罚。

## 视听表现

- **实时托卡马克剖面**：约束稳定度实时切换三档——蓝白稳定 / 橙色临界 / 暗红破裂。
- **破裂报警**：稳定度跌破阈值时触发报警音、脉动横幅与破裂科普弹窗；恢复后自动解除。
- **仪表角标**：「✓稳定」（超额奖励）/ 「⇌链路」（故障链激活）实时更新。
- **结局动画**：全屏播放对应命运的装置动画后，结局卡片滑入。
- **背景音乐**：主菜单 / 中控台 / 结局三段无缝循环原创配乐，程序合成。
- **等离子体粒子**：色调严格对应约束稳定度；粒子数性能可配。

> 所有视觉均为程序矢量 / 粒子，无图片依赖；音乐为程序合成原创音轨，无版权风险。

## 技术栈

- **引擎**：Godot 4.6（Forward+ 渲染器）
- **语言**：GDScript（100%）
- **特效**：GPUParticles2D 粒子 + Node2D `_draw` 程序矢量（托卡马克剖面 / 结局动画，无图片依赖）
- **音频**：程序合成原创 BGM + 事件音效，独立音量、跨场景持续
- **数据**：全部科普文本 / 故障逻辑 / 专家台词 / 结局文案外置 `res://data/*.json`
- **存档**：Godot `ConfigFile`（存档 / 设置 / 成就，纯 `user://` 本地）
- **导出**：Windows / macOS / Linux / HTML5

## 项目结构

```
res://
├── data/                      # 全部配置（JSON，非程序员可改）
│   ├── experts.json           # 四位专家性格与负责仪表
│   ├── faults.json            # 故障树：根因→四轮表象 + fault_chains
│   ├── scenarios.json         # 5 套手作剧本（激活根因/偏移/链/专家立场）
│   ├── rounds.json            # 仪表基准与每轮限时
│   ├── briefings.json         # 专家简报（precise / vague 双精度）
│   ├── endings.json           # 12 结局矩阵文案
│   ├── achievements.json      # 行为成就定义
│   ├── difficulty.json        # 四种难度参数
│   ├── balance.json           # 核心数值平衡（公式系数、奖惩阈值）
│   ├── popups.json            # 浮动科普标签
│   ├── kb_glossary.json       # 手册：科普词条
│   ├── kb_timeline.json       # 手册：成果/辟谣/就业
│   └── tutorial.json          # 教学战役三章配置
├── scripts/
│   ├── autoload/              # 单例：DataManager / GameState / SaveManager / AudioManager
│   ├── core/                  # 业务：FusionEngine / FaultTree / BriefingSystem / EndingResolver / TutorialCampaign
│   └── ui/                    # 视图脚本（含 TrendChart / TokamakAnimation 等）
├── scenes/
│   ├── menu/                  # 主菜单 + 设置面板
│   ├── control_room/          # 中控台主场景
│   ├── components/            # Gauge / BudgetToken / DropZone / BriefingCard / PopupTag
│   ├── panels/                # ManualPanel / LogPanel / EndingPanel / SettingsPanel
│   └── fx/                    # PlasmaCore / TokamakAnimation
└── assets/audio/              # 程序合成 BGM
```

**架构约定**：业务逻辑下沉 `scripts/core/`（纯函数式）；视图脚本只管交互与显示；所有数值禁止硬编码，集中于 `data/balance.json`；`DataManager.get_experts()` 自动过滤非 Dictionary 值（含 `_comment`），迭代安全。

## 运行与构建

### 在编辑器中运行

1. 用 **Godot 4.6+** 打开本项目目录（含 `project.godot`）。
2. 按 **F5** 运行。

### 命令行

```bash
# 导入资源后退出（首次校验）
"<Godot可执行文件>" --headless --path . --import
# 运行
"<Godot可执行文件>" --path .
```

### 导出

桌面三平台 + HTML5。HTML5 端建议粒子质量设为 `low`。导出产物完全离线，可直接上传 GitHub Pages 等静态托管。

**Web 导出关键配置**（`export_presets.cfg` 已设好）：

| 选项 | 值 | 原因 |
|------|----|------|
| 线程支持 | **关** | 开启需 COOP/COEP 响应头，GitHub Pages 不支持 |
| 入口文件名 | `index.html` | ASCII 命名，避免中文 URL 编码导致 `Failed to fetch` |
| 默认字体 | 思源黑体（SIL OFL） | Web 端无法取系统中文字体，必须随包内置 |

> 本地预览：`python -m http.server`，浏览器开 `http://localhost:8000/`（勿用 `file://`）。

### 自动部署（CI/CD）

仓库已配置 GitHub Actions：**推送到 `main` 分支即自动**用 Godot 4.6.3 headless 构建 Web 导出并发布到 GitHub Pages。首次使用需在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。
